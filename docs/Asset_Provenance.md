# Branding assets

The new icon and wallpaper were generated using the built-in image-generation tool. The user's silver/red NorthStar compass emblem supplied the style reference. Icon prompt: a polished silver/red compass with wireless arcs; no musical note, shield or lettering; transparent background. Wallpaper prompt: a dark graphite 16:9 desktop background using the wireless emblem, subtle red waves, clear left-hand space for shortcuts, and the app/publisher names. Small PNG and ICO sizes were derived from the generated emblem.

- assets/branding/northstar.png — app emblem
- assets/branding/northstar.ico — multi-size Windows EXE/window/installer icon
- assets/branding/product_image_800x800.png — square product artwork
- assets/branding/desktop_wallpaper.png — desktop artwork, supplied as an optional image; the installer does not change the user's wallpaper
- assets/branding/original_rf_artwork.png — original supplied RF image
- assets/icons/ — original supplied toolbar icons
